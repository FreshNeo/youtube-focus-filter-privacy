Privacy Policy — YouTube Focus Filter

Last updated: October 26, 2026

Overview

YouTube Focus Filter helps users filter YouTube search results based on keywords and user-selected preferences.

Information Processing

The extension processes YouTube search queries and video titles to apply filtering rules. These data are used for the extension's core functionality.

User preferences may be stored locally in the browser.

Data Sharing

The extension does not sell users' personal information. It does not transmit search queries, video titles, or filtering preferences to the developer's servers, provided that no such transmission is implemented in the published version.

Data Security

The extension is designed to perform filtering within the user's browser.

Children's Privacy

The extension is not specifically designed to collect personal information from children.

Changes to This Policy

This policy may be updated if the extension's functionality or data practices change.

Contact

For privacy questions or support, please use the support contact listed on the Chrome Web Store listing.
